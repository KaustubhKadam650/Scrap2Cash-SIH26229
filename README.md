# Scrap2Cash – SIH26229

Vernacular, low-literacy, offline-tolerant platform that connects informal scrap collectors with authorized recyclers.

## Live Prototype
https://scrap2cash-kabadiwalaconnect.netlify.app

## Features
- Collector + Recycler dual interface
- Marathi / Hindi / English support
- Camera + AI material recognition (simulated)
- Price discovery with spoken rates
- Smart recycler matching
- Digital traceable handover
- Earnings ledger
- Offline-first design

## Datasets
See the `/datasets` folder.  
Data was collected through field research with 2 informal scrap collectors in Bhusawal–Jalgaon region (Maharashtra).
